# BCSE Community Rights Registry

**Our Heritage. Our Authority. Our Future.**

The BCSE Community Rights Registry is an early-stage prototype for community-controlled organisation of governance records, supporting evidence, access permissions, objections and exports.

## Development status

This repository is in **Batch 0 — project foundation**. It is not approved for production use or real community records.

> **Synthetic-data-only rule:** Until legal, governance, privacy and security readiness gates are independently satisfied, use synthetic demonstration data only. Do not upload real names, contact details, genealogy, customary land boundaries, claims, sacred or secret knowledge, community documents, or other sensitive information.

## Product boundaries

BCSE is a record-organisation and workflow tool. It does not determine customary ownership, validate representation or consent, issue titles or certificates, resolve disputes, replace statutory institutions, or authorise land transactions or heritage licensing.

## Planned initial capabilities

- Community workspace shell
- Governance and representative record organisation
- Evidence portfolio and document metadata
- Community-controlled access and permission workflows
- Objection and complaint records
- Audit trail and portable exports

## Proposed technology

- Next.js and TypeScript
- Supabase PostgreSQL, Auth and private Storage (not connected yet)
- GitHub for source control and CI
- Automated unit, integration and browser tests

The initial implementation will be developed locally with synthetic data. No hosted database, production deployment, paid service or migration is authorised by this repository setup.
